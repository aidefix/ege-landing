# Лендинг курса подготовки к ЕГЭ по русскому языку

Боевой одностраничник частного преподавателя. Аудитория: родители 11-классников
(платят) и сами ученики (решают). Целевое действие — заявка на диагностику.

## Эталон дизайна

`docs/prototype.html` — утверждённый визуальный прототип. Он задаёт всё:
палитру, шрифты, композицию, тексты, интерактив. Сверяйся с ним перед каждой
секцией и повторяй визуал один в один.

НЕ копируй его код. Там всё инлайном — это осознанно для прототипа.
В проекте: токены в `globals.css`, разметка в компонентах, данные в `src/lib/data.ts`.

## Стек

Next.js 16 App Router, TypeScript strict, Tailwind v4 (CSS-first через `@theme`,
без `tailwind.config.js`), Radix UI (только примитивы), zod, `next/font`.

Без FSD, без TanStack Query, без стейт-менеджеров. Данные статические,
запрос ровно один — отправка заявки.

```
src/app/         layout, page, globals.css, api/lead/route.ts,
                 privacy/, consent/, offer/, sitemap.ts, robots.ts, opengraph-image.tsx
src/components/  sections/ и ui/
src/lib/         data.ts, quiz.ts, essay.ts, schema.ts, notify.ts
```

## Правила

- Серверные компоненты по умолчанию. `"use client"` — только тренажёр, разбор
  сочинения, выбор тарифа и форма.
- Контент не хардкодить в JSX: тексты, цены, программа, задания — в `src/lib/`.
- Плейсхолдеры `[ИМЯ]`, `[ГОД]`, `[N]`, `[ФИО]`, `[ИНН]` оставлять как есть.
- Комментарии — только там, где логика неочевидна.
- Никаких новых зависимостей без спроса. Иконок в проекте нет: звёздочки,
  галочки и крестики — текстовые глифы, как в прототипе.

## Чего не делать

Сине-фиолетовых градиентов, glassmorphism, одинаковых карточек с иконкой
в кружке, мягких теней. Тени только жёсткие, без размытия. Обводки толстые.
Стоковые фото не использовать вообще.

## Тон текста

Спокойный, конкретный, местами резкий. Цифры вместо прилагательных. Гарантий
баллов нет — есть статистика. Никаких восклицательных знаков в заголовках.
Обращение на «вы», на «ты» — нигде.
